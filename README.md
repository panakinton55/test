# 十二席

一人起業の12席を、今週の仕事に落とす画面。

自分が出るのは経営、プロダクト、営業と、その週の出力ひとつ。出力は「出荷する」か「届ける」のどちらかで、開発と発信を同じ週の必須にしない。問い合わせは来た日だけ。顧客成功と管理は、問題がなければ何もしない。デザイン、インフラ、収益、財務は渡し、月の初めに動いているかだけ見る。

記録はこのブラウザの中だけ。週が変わると「終えた」は戻り、メモは残る。

## 開く

`index.html` を静的に配信して開く。

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

ブラウザで `http://127.0.0.1:8765/` を開く。

## 確認

```bash
npm test
```
